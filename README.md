# Расшифровка звонков Битрикс24

Расширение Chrome: в карточке лида, сделки или контакта у каждой записи
разговора появляются две кнопки — **«Расшифровать»** и **«Скачать»**. Стоят они
в штатной строке действий, слева от «…», и выглядят как родные кнопки портала.
Расшифровка делается через Yandex SpeechKit по вашему ключу и открывается в
редакторе, где текст можно поправить и разметить, кто говорит.

Работает на облачных порталах (`*.bitrix24.ru`) и на коробочных — расширение
привязано не к домену, а к адресам вида `/crm/…`.

## Зачем это, если в Битрикс24 есть BitrixGPT

Встроенная расшифровка действительно есть: BitrixGPT (бывший CoPilot) умеет
переводить запись в текст, делать резюме разговора и заполнять поля карточки —
[документация Битрикс24](https://helpdesk.bitrix24.ru/open/18799442/). Если она у
вас включена и вас устраивает, это расширение вам не нужно.

Оно писалось для случаев, когда встроенная не подходит:

- **Её может не быть на портале.** Каждое действие BitrixGPT — это запрос из
  пакета, а для работы без лимитов нужна подписка BitrixGPT + Маркетплейс; на
  коробочных порталах это отдельные
  [бусты](https://helpdesk.bitrix24.ru/open/23952962/). На портале, где
  расширение обкатывалось, кнопки расшифровки в меню звонка нет вовсе.
- **Оно не отдаёт файл.** Встроенная расшифровка показывает текст внутри
  Битрикса; выгрузить запись и разобрать её своими средствами она не помогает.
  Когда телефония внешняя, записи не попадают и в папку «Телефония» на Диске —
  они лежат файлами CRM, и штатного «скачать» у них нет.
- **Никакой ИИ не разметит роли в моно-записи.** Если оба голоса в одной
  дорожке, разделить их нечем. Поэтому здесь не делается вид, что роли известны:
  расширение расставляет их через одного и даёт человеку экран, где это
  исправляется одним кликом на строке.
- **Свой ключ, свои деньги.** Расширение ходит в Yandex SpeechKit напрямую с
  вашим ключом. Никакого промежуточного сервера нет, записи никуда, кроме
  Яндекса, не уходят.

## Установка

1. Скачайте архив: [последний релиз](https://github.com/violoctecia/bitrix-call-transcriber/releases/latest)
   или [весь репозиторий одним zip](https://github.com/violoctecia/bitrix-call-transcriber/archive/refs/heads/main.zip).
2. Распакуйте папку.
3. Откройте `chrome://extensions`, включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку.

Обновление — скачать архив заново, заменить файлы и нажать «Обновить» на
карточке расширения.

## Настройка ключа

Скачивание записей работает сразу. Для расшифровки нужен ключ Yandex SpeechKit:

1. В консоли Яндекс.Облака создайте сервисный аккаунт.
2. Выдайте ему роль `ai.speechkit-stt.user`.
3. Создайте API-ключ и вставьте его в настройках расширения вместе с
   идентификатором каталога (`b1g…`).

Ключ хранится в `chrome.storage.local`, то есть в профиле браузера, и
отправляется только на `stt.api.cloud.yandex.net`.

Распознавание платное, тарифицируется по секундам. Пятиминутный разговор стоит
копейки, но счёт ваш — следите за расходом в консоли облака.

## Как работает

Карточка CRM рисуется внутри `iframe`, и плеер записи живёт там же, поэтому
content script объявлен с `all_frames: true`. Сам файл отдаётся штатным
обработчиком портала:

```
/bitrix/tools/crm_show_file.php?fileId=…&ownerTypeId=…&ownerId=…
```

Скрытый `<audio>` с этим адресом стоит в DOM сразу, до нажатия play — поэтому
кнопки появляются при открытии карточки.

Расшифровка идёт в отдельной вкладке, а не в служебном воркере: Chrome усыпляет
воркер через полминуты простоя, и длинная запись до конца бы не доехала.
Страница скачивает mp3 по вашей же сессии, сводит его в моно 8 кГц (записи
телефонные, выше частота ничего не добавляет, а в синхронную ручку SpeechKit
нельзя послать больше мегабайта), **режет по паузам, а не по таймеру** — так
каждый кусок оказывается отдельной репликой с честным временем начала — и
распознаёт их по четыре одновременно.

Редактор показывает реплики со временем, подсвечивает текущую по ходу
воспроизведения, даёт править текст прямо в строке, склеивать разорванные фразы,
убирать шум и переключать роль кнопкой «О / К / ?». Готовое выгружается в txt
или копируется в буфер. Черновик сохраняется в браузере: закрытая вкладка
ничего не теряет, и повторно платить за распознавание той же записи не придётся.

## Чего оно не делает

- Не скачивает записи пачкой — работает по одной карточке.
- Не ставит знаки препинания: синхронная ручка SpeechKit их не расставляет.
- Не различает говорящих: для этого нужна стереозапись либо асинхронное
  распознавание с загрузкой файла в Object Storage.
- Не трогает данные портала — только читает страницу и скачивает файл.
